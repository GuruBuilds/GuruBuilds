### 🛠 Next Steps to Make It Dynamic

#### ✅ 1. WakaTime Setup

1. Sign up on [https://wakatime.com](https://wakatime.com)  
2. Get your WakaTime API Key  
3. Add it as a **GitHub Secret** in your repo:
   - Go to `Settings > Secrets and variables > Actions`
   - Add a new secret: `WAKATIME_API_KEY`
4. In your GitHub profile repo, create `.github/workflows/waka.yml` with:

```yaml
name: Waka Readme

on:
  schedule:
    - cron: '0 * * * *' # every hour
  workflow_dispatch:

jobs:
  update-readme:
    name: Update Waka Stats
    runs-on: ubuntu-latest
    steps:
      - uses: athul/waka-readme@master
        with:
          WAKATIME_API_KEY: ${{ secrets.WAKATIME_API_KEY }}
```

#### ✅ 2. Blog Posts from Dev.to

If you write blogs on [Dev.to](https://dev.to), you can add this:

```yaml
name: Latest blog post workflow
on:
  schedule:
    - cron: '0 * * * *'
  workflow_dispatch:

jobs:
  update-readme-with-blog:
    name: Update this repo's README with latest blog posts
    runs-on: ubuntu-latest
    steps:
      - uses: gautamkrishnar/blog-post-workflow@master
        with:
          feed_list: "https://dev.to/feed/YOUR_DEVTO_USERNAME"
```

Let me know your Dev.to or Medium link if you'd like that added right away!
